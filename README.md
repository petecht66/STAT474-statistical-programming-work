# STAT474-statistical-programming-work
Completion Timeline for STAT474: August to December 2024
Last Updated on GitHub: June 1, 2026

This repository contains my complete work for STAT474: Statistical Programming at the University of Delaware College of Agriculture and Natural Resources Department of Applied Economics and Statistics. I completed this course in the Fall of 2024, with Dr. Dianne Farina-Sisofo being the course instructor. The purpose of this course was to introduce students to statistical programming methods in Statistical Analysis Software (SAS) and R.

The first half of the course was dedicated to SAS, while the second half dealt with R. SAS OnDemand for Academics and R Studio were the two programming environments used for course instruction. After the conclusion of this course, I downloaded R and set up a programming environment in VS Code. I download any necessary packages as I need them for my work. This course was very much an introduction to SAS and R; I have since become much more proficient with these languages, especially with regression analysis techniques.

Dr. Farina-Sisofo's University of Delaware page: https://www.udel.edu/academics/colleges/canr/departments/applied-economics-and-statistics/faculty-staff/dianne-farina-sisofo/
